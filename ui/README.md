# XX 射击俱乐部小程序 UI

打开 `index.html` 即可体验，无需安装依赖。此交付为 UI 交互原型，未接入微信云开发、微信支付或真实物流。

## 已实现界面

- 首页：门店切换、训练权益、近期课程、教练预约、会员卡推荐、商品与拼团。
- 教练预约：展示多位教练及各自可授课程，按教练和日期查看已发布时段。私教会员只能选择教练预先发布的时间，不能自行创建时间段；确认页展示教练、课型、门店及使用的私教卡。
- 会员卡：三种课型筛选、10次与50次卡、规则和模拟购卡。
- 预约：日期筛选、三种课型、名额、约满与无排课状态、预约确认、成功及取消。
- 商城：搜索、分类、商品详情、购物车数量、地址校验、运费与模拟支付。
- 我的：会员卡切换、冻结次数、预约、订单、拼团、地址与使用记录。

底部预约为中央凸起的68px圆形按钮。名称统一为XX，移除了原型外围说明与宣传性标题。

预约入口统一到该页面的「按课程预约 / 按教练预约」两种模式。首页仅显示2位推荐教练；全部教练入口进入预约页，可搜索姓名、筛选课型，每批展示6位。点击教练在预约页内查看课程和时段，仅最终预约确认使用底部弹层。

## 设计约定

主色 #17362E，重点色 #DCF58B，页面底色 #F5F5EF。页面以375px宽度为移动端基准，卡片圆角20px，常用按钮高度44至48px。图标和商品图采用可替换的内联SVG，人物使用占位图。

## 业务假设

示例价格、门店、商品、人物均待替换。示例采用仅本店使用、按课型独立次卡、购买当天起算、开课前24小时取消返次、总部发货及满299元包邮。以上需在实际开发前确认，不代表已确定的经营政策。多门店收款主体仍未确定。

预约示例将次数从可用转为冻结，取消后返还；不模拟真实核销。所有支付按钮明确标为模拟。数据仅保留在当前页面会话，刷新后重置；不产生实际订单、扣款、发货或分享消息。

教练排班由后台维护：教练选择课程、门店、日期及起止时间，校验教练和场地冲突后发布；私教时段容量为1。会员端读取已发布的时段，约满后不可选。当前原型以 publishedClasses 示例记录模拟后台发布结果，真实教练编辑管理端尚未实现。

## 下一步开发

将页面拆分为小程序页面及组件；使用云函数校验门店、课型、库存、次数和权限；将交易逻辑接入真实支付回调及幂等处理。浏览器原型的本地状态不能直接作为生产后端。
